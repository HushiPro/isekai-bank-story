# 小段级模拟器剧本

改写柜员线剧情时，按下面两条执行，用原话，不放宽：

1. 把故事分为小段级，比如说第一章主要说了主角通过死缠烂打从导师那获得了一份工作（第一个小段），到达储蓄所（第二个小段），和做第一笔生意（第三个小段）
2. 把每个小段单拆出来，减弱文学性，加强剧本性，同时保证故事有趣，适合第一人称模拟器类游戏的文案

玩家就是柜员。正文用「我」，不写小说叙述者。

## 先切段，再写

读完来源后再落笔。一段只有一个玩家目标，一段一个文件。

第一章 `另一个方向/剧情/开局故事_第一章_柜员线_v1.txt` 的切点固定为：

| 小段 | 玩家目标 | 来源大约从哪到哪 |
| --- | --- | --- |
| 1 获得工作 | 死缠烂打，从导师手里拿到任命 | 开头到「今晚可以住在车上」 |
| 2 到达储蓄所 | 抵达灰桥镇支行，接手这个网点 | 「十八天后」到第一位客人开口办事之前 |
| 3 第一笔生意 | 办完第一笔存款 | 客人开始存款，到这笔入账记完 |

这三项目标之后的内容（税单、下一位客人）不要塞进第三段。列成「未归段」，等用户决定是否新开一小段。

其他章节按同样粒度切：一个能当场做完的目标，不是整章，也不是每一句对白。切点有歧义时先列出段名和边界，确认后再写。

## 写的时候

每段单独存成 `另一个方向/文案/NN_段名.txt`。不改文学原稿，除非用户明确要求覆盖。

一段用这个结构：

```text
第X章 · 小段N：段名
目标：这一段玩家要办成的一件事
地点：
在场：

【开场】
我能立刻知道的现状，两三句。

【我能做】
- 调查：点得到的东西，和点开后的一句结果
- 对话：找谁说
- 办理：柜面步骤（只在有业务时写）

角色名：台词
我：台词

【必须发生】
按顺序写触发节拍。一步一件事。

【段末】
玩家拿走什么，下一段从哪接。
```

减弱文学性：

- 删成段风景、比喻堆叠、作者总结（「这是一份事业」这类判断改成我的一句台词，或删掉）
- 玩家看不见、点不了的信息不要写进正文；背景只留在【调查】里，一条一个事实
- 心理活动不能变成台词、选项或【我能做】，就删
- 原稿里的设计备注（括号、`#`）放进文末【设计】，不进玩家能读到的正文

加强剧本性：

- 对白一行一句，说话人写在行首
- 动作写成玩家能做的事：坐下、调查、对话、清点、盖章
- 「他数了两遍」改成办理步骤：清点、复核、请对方确认
- 笑点留在情境和对白里，不另起一段解释为什么好笑

仍要有趣：保留原段的喜剧情境和信息差（门口堵导师、地图越展越远、行李已经被收好、第一笔是照顾新人的教学存款）。不把段子抹平，也不把段子讲透。

## 写完自查

- [ ] 一段一目标，文件已拆开
- [ ] 玩家目标用原文能对上，没有把下一段的事写进来
- [ ] 正文是「我」，没有叙述者抒情
- [ ] 有【我能做】，而且段末拿得到具体结果
- [ ] 笑话还在对白里
- [ ] 设计备注不在正文里

## 示例

原稿：

```text
洛恩毕业后的第十五天，依然每天准时到学院报到。
只不过他现在上的课，名字叫《如何让导师给我找一份工作》。
授课地点是塞维尔导师的办公室门口。
```

小段正文：

```text
【开场】
毕业第十五天。我又坐在塞维尔导师办公室门口。
今天的课只有一门：让他给我找一份工作。

【我能做】
- 调查椅子：学院的。我每天来都搬这一把。
- 对话塞维尔：等他开门。

塞维尔：你为什么还在这里？
我：等您改变主意。
塞维尔：我昨天已经说过，学院今年没有职位。
我：您前天也是这么说的。
```
