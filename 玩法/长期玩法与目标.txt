一、先确定整个游戏的母循环
最适合这个题材的母循环是：

发现明确价差 → 买入或提供资金 → 等待短期变化 → 结算获利 → 扩大经营能力

例如：

农民急需现金，把价值12银币的麦子以8银币出售。
玩家买入。
可以立刻以10银币卖给本地面包店，净赚2银币。
也可以囤到三天后的军队采购，以15银币出售。
利润用于扩建仓库、增加现金或雇佣情报员。
玩家从一开始就有一个安全答案：

立刻转卖：利润少，但马上获得正反馈。
囤货投机：利润高，但承担事件和仓储风险。
信息能力应该帮助玩家多赚一些钱，而不是决定玩家能否避免莫名其妙的失败。

此后所有金融业务都围绕这个母循环服务：

存款：让玩家有更多钱收货。
贷款：将别人的抵押品和时间需求变成利润。
汇兑：利用不同货币之间的价差。
保险：通过承担可计算的风险收取费用。
期货：提前锁定未来买卖价格。
股权：创造新的生产者和商品来源。
债券：建设道路、仓库和码头，扩大整个市场。
二、第一层玩法：贸易收购
这是最基础、最接近当铺游戏的部分。

简单循环
顾客带货上门 → 玩家鉴定 → 报价收购 → 选择销售渠道 → 获得利润

每件货物明确显示：

大致价值范围。
本地立即出售价格。
占用仓库空间。
腐烂或损坏速度。
可能需要该商品的地区。
例如，一名魔物娘果农带来十箱月光莓：

对方开价：每箱7银币。
本地酒馆立即收购价：每箱9银币。
三天后精灵庆典预测价格：每箱14银币。
每天有10%的腐烂概率。
玩家即使完全不懂市场，也可以低价收购后立刻卖给酒馆，获得稳定利润。了解事件和升级仓库的玩家则可以囤货。

这个循环的成长内容
更高的鉴定能力：缩小价值范围。
更强的议价能力：降低收购价格。
更大的仓库：允许囤积更多货物。
冷藏魔法：延长易腐商品保质期。
更多销售渠道：解锁其他城市的价格。
熟客关系：提前获知对方下次会带什么货。
这是游戏最早期的主要赚钱方式，不需要立即出现银行。

三、第二层玩法：抵押贷款
抵押贷款可以直接继承当铺循环，而且比无抵押信用贷款容易理解。

简单循环
顾客带抵押物借钱 → 玩家估价 → 决定贷款金额 → 到期收回本金和利息，或者获得抵押物

例如：

一名矮人工匠带来价值50银币的锻造锤，想借30银币购买铁矿。

玩家可以选择：

借20银币：安全，但收益较低。
借30银币：正常风险。
借45银币：收益更高，但一旦锤子价格下跌就可能亏损。
拒绝贷款。
三天后只有两种直观结果：

工匠还款33银币，玩家赚3银币。
工匠无法还款，玩家获得锻造锤，可以按当前市场价格出售。
这仍然是“低价获得商品，再出售获利”的循环，只是获得商品的方式从收购变成了抵押违约。

抵押物可以体现种族差异
人类农民：粮食、土地收成权、牲畜。
矮人工匠：工具、矿石、未来订单。
魔物娘施法者：魔法材料、部族担保、季节性产出。
商队：整批货物和运输车辆。
贵族：税收权、地产收入和珠宝。
早期只出现容易估价的实物。未来订单、收成权和税收权放到中期再开放。

四、第三层玩法：货币兑换
汇兑不需要做成复杂的金融系统，可以是一种短而频繁的鉴定玩法。

简单循环
客人拿外币上门 → 玩家检查重量和成色 → 给出报价 → 赚取兑换差价

例如：

一枚标准矮人银币价值1.2枚人类银币。
玩家以1.1的价格收进。
再以1.18的价格卖给准备进入矮人地区的商队。
玩家赚取中间差价。
主要风险只有两种：

银币成色不足。
假币或削边币。
相关升级包括：

更准确的天平。
金属试剂。
矮人铸币顾问。
各国官方兑换许可。
自动兑换柜台。
汇兑的正反馈是即时的，每次交易结束都会直接获得利润。后期可以自动化，成为稳定现金流，不必让玩家永久重复操作。

五、存款不是独立小游戏，而是“扩大本金”的系统
存款本身缺少即时操作快感，因此不要强迫玩家逐个处理储户。它更适合作为贸易和放贷系统的增幅器。

简单循环
提高信誉或利率 → 吸引存款 → 获得更多可用资金 → 收购更多货物 → 留出现金应付提款

例如：

玩家原本只有100银币，只能买十箱货物。吸收200银币经营存款后，可以同时进行更多交易，但每天可能有一部分储户提款。

玩家只需要决定三个数值：

存款利率。
现金储备比例。
最多动用多少存款经营。
游戏直接提示风险：

现金充足。
提款压力上升。
当前储备只能应付预计提款的70%。
不要让玩家计算几十笔存款，也不要隐藏正常提款需求。存款玩法的乐趣来自“我现在可以买更多东西”，而不是记账。

六、商队投资：把贸易变成短周期远征
商队业务可以承担类似派遣任务的玩法。

简单循环
选择路线 → 选择货物 → 配置护卫和保险 → 商队出发 → 数日后带回利润

每条路线应当明确显示：

推荐商品。
预计利润区间。
所需时间。
盗匪、天气和战争风险。
是否有可靠的当地联系人。
例如：

森林路线适合运送铁器：

投入：100银币。
正常收入：140银币。
时间：三天。
盗匪风险：低。
道路中断风险：中。
货物损坏风险：低。
玩家可以购买护卫、维修马车或者分散货物。结果应在几天内结算，而不是等待一个游戏季度。

保险如何加入
最初玩家只是给自己的商队购买保险。理解风险之后，才允许玩家为别人的商队承保。

承保循环是：

查看路线风险 → 收取保费 → 商队出发 → 无事发生则保费成为利润，出事则赔付

一次只针对一条路线，不要一开始就引入复杂保险组合。

七、订单与期货：从“猜价格”变成“提前锁定利润”
期货如果只表现为价格曲线，会显得抽象。更适合先从订单合同开始。

简单循环
客户发布未来订单 → 玩家寻找便宜货源 → 提前购入或签订供货合同 → 到期交货获利

例如，军队宣布：

五天后收购100件标准铁制农具，每件支付18银币。

当前市场价格是12银币。玩家可以：

立即购买农具并囤积，锁定每件6银币的毛利润。
给矮人工坊预付款，要求五天后以每件14银币交货。
不持有货物，只与另一名商人签订16银币的转让合同。
判断铁价会上涨，买入更多进行投机。
玩家一开始看到的是一个明确订单，而不是难以理解的期货界面。标准化订单足够多以后，才逐渐形成正式的期货市场。

八、股权投资应该表现为“养成一家店”
单纯点击股票并等待价格上涨，和城镇没有情感联系。股权投资应该与具体经营者绑定。

简单循环
发现有能力但缺钱的经营者 → 投资店铺 → 帮助解决生产问题 → 店铺升级 → 定期获得分红

例如，一名矮人工匠想开设农具工坊：

玩家投资200银币，占有30%股份。
帮他购买水车和熔炉。
为工坊寻找铁矿供应商。
工坊开始生产，镇上出现新的建筑和工人。
玩家定期获得利润分红。
工坊生产的农具又成为玩家可以交易和抵押的商品。
投资结果会直接改变城镇外观和商品供给，这比抽象的股权数字更有反馈感。

失败也要可理解
店铺失败应该来自玩家看得见的问题：

原料不足。
没有订单。
负责人经营能力低。
竞争者降价。
工人罢工。
不要用一次隐藏随机数决定投资项目破产。

九、债券应该表现为“集资建设城镇”
债券适合作为中后期城镇建设系统，而不是普通商品。

简单循环
选择公共项目 → 估算收益 → 发行债券募集资金 → 项目建成 → 新增税收或经营收入偿还债券

例如修建新桥：

建设成本：5000银币。
玩家自己出资：1000银币。
向居民和商人发行债券：4000银币。
建成后商队数量增加30%。
每支过桥商队支付费用。
过桥费承担债券利息和本金。
玩家获得：

债券发行手续费。
持有债券的利息。
商队增加带来的更多客户。
城镇 visibly 扩张。
这里的正反馈不仅是数字增长，而是桥梁真的出现、市场变大、新商人来到镇上。

十、事件系统必须服务于循环，不能替代循环
事件应该创造明确机会，而不是让玩家提前猜出设计者的答案。

合理的事件呈现
例如公告板明确显示：

三天后举行丰收节。酒类、肉类和香料需求预计上升。

玩家知道受影响的商品和时间，可以选择参与，也可以继续做安全买卖。

随着情报系统升级，玩家获得更早或更准确的消息：

普通玩家提前三天知道需求会上升。
有酒馆关系的玩家提前五天知道。
有贵族关系的玩家知道宴会规模，能够估算具体需求。
情报可能不完整，但不应该完全隐瞒事件方向。
信息能力的正确作用
信息不应该决定“会不会莫名其妙亏光”，而应该影响：

玩家多早知道机会。
价格预测区间是否准确。
是否知道某个客户急需现金。
是否发现货物隐藏瑕疵。
是否知道竞争者正在囤货。
安全利润永远存在，情报只是提高利润上限。

十一、重新设计第一周教程
原本的三商队事件可以保留，但应当放在第一章结尾。

第一天：直接买卖
果农急需现金，以6银币出售月光莓。本地酒馆愿意以8银币立即收购。

玩家完成第一次低买高卖，立刻赚钱。

第二天：囤货
公告显示两天后有庆典，月光莓预计涨到12银币。

玩家学习立即出售和囤货之间的区别。

第三天：鉴定与议价
客人带来一批品质不一的香料。玩家学习检查品质并压价。

第四天：抵押贷款
矮人工匠抵押工具借款。玩家学习抵押率、利息和违约处理。

第五天：存款
一名富商存入资金。玩家第一次利用外部资金扩大收购规模，同时保留现金准备提款。

第六天：订单
农民行会发布农具订单。玩家收购或预订矮人工坊的产品。

第七天：三支商队抵达
此时玩家已经分别理解：

易腐商品。
商品抵押。
现金储备。
未来订单。
不同货币。
三支商队事件成为第一章的综合挑战，而不是玩家第一次打开游戏就面对的复杂难题。

十二、控制系统复杂度的原则
整个游戏前期只需要让玩家持续关注三项资源：

现金：决定当前能做多少生意。
仓库：决定能囤多少货。
信誉：决定客户、存款和订单规模。
进入中期后，再增加：

流动性：能否满足提款和短期债务。
风险准备金：能否承担保险和贷款违约。
政治关系：三国如何对待银行。
会计、清算、仓单、商业法庭等内容可以存在于世界观中，但不一定都要做成独立小游戏。它们更适合作为升级项目，为核心循环提供被动效果。

最终玩法结构可以概括为：

贸易负责即时赚钱，贷款负责稳定赚钱，商队负责周期赚钱，投资负责长期成长，金融工具负责放大规模和控制风险。

这样玩家始终在重复一个容易理解的行为：找到价差并利用它。银行的发展不是突然切换成另一种游戏，而是让玩家能用更多人的钱、跨越更远的距离、承担更大的交易。
